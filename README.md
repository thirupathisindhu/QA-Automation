# QA Automation – Authentication Module

This project demonstrates automated testing of a web application's
authentication module using Selenium and Pytest.

## Features Covered
- Login with valid credentials
- Login with invalid credentials
- Error message validation
- Forgot Password workflow
- HTML Test Report generation
